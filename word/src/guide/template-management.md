# 模板管理

本文档详细介绍 DeEarthX-CE 软件的模板管理功能，帮助您充分利用模板系统的强大功能。

## 模板概述

模板是 DeEarthX-CE 的一项核心功能，允许用户创建、管理和共享服务端配置模板。模板包含以下信息：

- **基本信息**：模板名称、描述、版本
- **适用范围**：Minecraft 版本、模组加载器类型
- **服务端配置**：内存分配、启动参数、JVM 选项
- **服务器属性**：游戏规则、难度、模式、最大玩家数等
- **模组配置**：预设的模组列表、模组配置文件
- **自定义设置**：服务器图标、欢迎消息、白名单等

### 模板的优势

- **提高效率**：使用模板可以快速生成配置一致的服务端
- **标准化配置**：确保所有服务端使用相同的最佳配置
- **易于共享**：导出模板与其他用户共享配置
- **版本控制**：通过模板版本管理不同配置版本

## 本地模板

### 创建模板

1. **进入模板管理界面**
   - 点击左侧导航栏中的「Galaxy」选项

2. **创建新模板**
   - 点击「创建模板」按钮
   - 填写模板基本信息：
     - **模板名称**：模板的唯一标识，建议使用描述性名称
     - **描述**：模板的详细说明，包括模板的用途、特点等
     - **版本**：模板版本号，建议使用语义化版本号（如 1.0.0）
     - **Minecraft 版本**：适用的 Minecraft 版本（如 1.19.4）
     - **模组加载器**：适用的模组加载器（Forge、NeoForge、Fabric）

3. **配置模板参数**
   - **服务端配置**：
     - 内存分配：设置服务端最大内存（如 4G）
     - 启动参数：配置 JVM 启动参数
     - 服务器类型：选择服务器类型（如 Vanilla、模组服务器）
   - **服务器属性**：
     - 游戏规则：配置游戏规则（如 keepInventory、doMobSpawning 等）
     - 难度：设置游戏难度（和平、简单、普通、困难）
     - 模式：设置游戏模式（生存、创造、冒险、旁观）
     - 最大玩家数：设置服务器最大玩家数
     - 服务器名称：设置服务器在多人游戏列表中的名称
   - **模组配置**：
     - 预设模组：添加常用模组到模板
     - 模组配置文件：上传或编辑模组配置文件

4. **保存模板**
   - 点击「保存」按钮，完成模板创建
   - 模板会自动添加到本地模板列表

### 编辑模板

1. **选择模板**
   - 在本地模板列表中选择要编辑的模板

2. **编辑模板信息**
   - 点击「编辑」按钮
   - 修改模板基本信息和配置参数
   - 可以修改任何模板参数，包括基本信息、服务端配置、服务器属性等

3. **保存更改**
   - 点击「保存」按钮，完成模板编辑
   - 模板的版本会自动更新

### 删除模板

1. **选择模板**
   - 在本地模板列表中选择要删除的模板

2. **删除模板**
   - 点击「删除」按钮
   - 在确认对话框中点击「确定」按钮
   - 模板会从本地模板列表中移除

### 导出模板

1. **选择模板**
   - 在本地模板列表中选择要导出的模板

2. **导出模板**
   - 点击「导出」按钮
   - 选择保存位置，保存模板文件（.dextpl 格式）
   - 导出的模板文件可以与其他用户共享

### 导入模板

1. **导入模板文件**
   - 点击「导入模板」按钮
   - 选择要导入的模板文件（.dextpl 格式）
   - 点击「打开」按钮

2. **确认导入**
   - 查看模板信息，确保模板与当前软件版本兼容
   - 点击「确认」按钮，完成模板导入
   - 导入的模板会自动添加到本地模板列表

## 模板商店

### 浏览模板

1. **进入模板商店**
   - 点击「模板商店」选项卡

2. **浏览模板**
   - 浏览可用的模板，模板按类别和流行度排序
   - 查看模板的详细信息，包括名称、描述、适用版本、下载次数等

### 下载模板

1. **选择模板**
   - 点击模板卡片查看详细信息
   - 查看模板的详细描述、适用范围和用户评价

2. **下载模板**
   - 点击「下载」按钮
   - 等待下载完成
   - 下载的模板会自动添加到本地模板列表

### 搜索模板

1. **使用搜索功能**
   - 在搜索框中输入关键词（如「生存」、「创造」、「模组包」等）
   - 点击搜索按钮
   - 查看搜索结果，按相关性排序

### 筛选模板

1. **使用筛选功能**
   - **按 Minecraft 版本筛选**：选择特定的 Minecraft 版本
   - **按模组加载器类型筛选**：选择 Forge、NeoForge 或 Fabric
   - **按模板类型筛选**：选择生存、创造、模组包等类型
   - **按更新时间筛选**：选择最近更新的模板

### 模板评分和评论

- **查看评分**：查看其他用户对模板的评分
- **查看评论**：查看其他用户对模板的评论和反馈
- **提交评分**：对已下载的模板进行评分
- **提交评论**：分享您对模板的使用体验和建议

## 模板使用

### 应用模板

1. **选择模板**
   - 在本地模板列表中选择要使用的模板

2. **应用模板**
   - 点击「应用模板」按钮
   - 选择要应用模板的整合包
   - 按照提示完成操作

### 模板与整合包结合

1. **选择模式**
   - 在 DeEarth 界面中选择工作模式（开服模式或上传模式）

2. **上传整合包**
   - 上传您的整合包文件

3. **选择模板**
   - 在处理过程中，点击「选择模板」按钮
   - 从本地模板列表中选择要应用的模板
   - 点击「确认」按钮

4. **处理整合包**
   - 软件会根据模板配置处理整合包
   - 生成的服务端会包含模板中配置的所有参数

### 模板预览

- **预览模板**：在应用模板前，可以预览模板的配置详情
- **比较模板**：可以比较不同模板的配置差异
- **自定义模板**：在应用模板时，可以临时修改模板的部分配置

## 模板最佳实践

### 1. 创建通用模板

创建适用于不同整合包的通用模板，包含基本的服务器配置和常用模组：

- **基础生存模板**：适用于基本的生存服务器
- **创造模式模板**：适用于创造模式服务器
- **模组包模板**：适用于包含大量模组的服务器

### 2. 创建专用模板

为特定类型的整合包创建专用模板：

- **生存模式模板**：配置适合生存模式的游戏规则和难度
- **创造模式模板**：配置适合创造模式的游戏规则和权限
- **模组包模板**：针对特定模组包优化配置
- **小型服务器模板**：适合玩家数量较少的服务器
- **大型服务器模板**：适合玩家数量较多的服务器

### 3. 定期更新模板

随着 Minecraft 版本和模组的更新，定期更新模板以保持兼容性：

- **更新 Minecraft 版本**：当 Minecraft 版本更新时，更新模板的适用版本
- **更新模组版本**：当模组更新时，更新模板中的模组版本
- **优化配置**：根据服务器运行情况，优化模板配置

### 4. 共享模板

导出模板并与其他用户共享，促进社区协作：

- **导出高质量模板**：创建和导出高质量的模板
- **分享模板**：在社区论坛、社交媒体等平台分享模板
- **接收反馈**：根据其他用户的反馈改进模板

### 5. 备份模板

定期备份本地模板，避免数据丢失：

- **导出模板**：定期导出重要的模板
- **备份模板文件**：将导出的模板文件存储在安全的位置
- **版本控制**：使用版本控制系统管理模板文件

### 6. 模板组织

- **分类管理**：根据用途和类型对模板进行分类
- **命名规范**：使用清晰、描述性的名称命名模板
- **版本管理**：使用语义化版本号管理模板版本

## 模板格式

模板文件采用 JSON 格式，包含以下主要字段：

```json
{
  "name": "模板名称",
  "description": "模板描述",
  "version": "1.0.0",
  "minecraftVersion": "1.19.4",
  "modLoader": "Forge",
  "serverConfig": {
    "memory": "4G",
    "jvmArgs": "-XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200",
    "serverType": "modded"
  },
  "serverProperties": {
    "difficulty": "normal",
    "gamemode": "survival",
    "max-players": "20",
    "server-name": "DeEarthX Server",
    "spawn-protection": "16",
    "white-list": "false"
  },
  "mods": [
    {
      "name": " jei",
      "version": "11.6.1.1015",
      "modId": "jei"
    }
  ],
  "customSettings": {
    "server-icon": "data:image/png;base64,...",
    "motd": "Welcome to DeEarthX Server!"
  }
}
```

## 高级模板功能

### 1. 模板变量

- **环境变量**：在模板中使用环境变量，如 `${SERVER_PORT}`
- **动态配置**：根据整合包内容自动调整模板配置
- **条件配置**：根据特定条件应用不同的配置

### 2. 模板继承

- **基础模板**：创建基础模板作为其他模板的父模板
- **继承配置**：子模板继承父模板的配置，只修改需要的部分
- **模板链**：创建模板继承链，实现配置的层次化管理

### 3. 模板导入导出高级选项

- **选择性导出**：只导出模板的部分配置
- **模板合并**：将多个模板合并为一个新模板
- **模板转换**：将模板从一个 Minecraft 版本转换到另一个版本

### 4. 模板验证

- **配置验证**：验证模板配置的正确性
- **兼容性检查**：检查模板与特定整合包的兼容性
- **性能评估**：评估模板配置的性能影响

## 故障排除

### 问题：模板创建失败

**解决方案**：
- 检查模板名称是否已存在
- 确保填写了所有必填字段
- 检查磁盘空间是否充足
- 检查模板配置是否符合要求

### 问题：模板导入失败

**解决方案**：
- 检查模板文件格式是否正确
- 确保模板文件没有损坏
- 检查模板版本是否与软件版本兼容
- 检查模板文件大小是否超过限制

### 问题：模板应用失败

**解决方案**：
- 检查模板是否与整合包兼容
- 确保整合包格式正确
- 检查网络连接是否正常
- 检查磁盘空间是否充足

### 问题：模板下载失败

**解决方案**：
- 检查网络连接是否正常
- 稍后重试
- 检查模板商店服务器是否可访问
- 尝试使用其他网络环境

### 问题：模板配置无效

**解决方案**：
- 检查模板配置是否符合 Minecraft 服务器要求
- 确保模板中的模组版本与整合包兼容
- 检查服务器属性配置是否正确
- 查看服务器日志了解具体错误

如果您遇到其他问题，请参考 [错误码](../error-codes.md) 文档或联系技术支持。
