# 使用指南

本文档详细介绍 DeEarthX-CE 软件的使用方法和功能，帮助您充分利用软件的各项特性。

## 主界面

启动 DeEarthX-CE 后，您将看到主界面，包含以下选项：

- **DeEarth**：主功能界面，用于处理整合包，是软件的核心功能区域
- **Galaxy**：模板管理界面，用于创建、编辑、导入/导出模板和浏览模板商店
- **Setting**：设置界面，用于配置软件的各项参数
- **About**：关于界面，显示软件版本、版权信息和开发团队

### 主界面布局

- **左侧导航栏**：包含上述四个主要功能选项
- **右侧内容区**：根据选择的功能选项显示相应的内容
- **顶部状态栏**：显示软件版本、当前状态等信息
- **底部状态栏**：显示处理进度、网络状态等信息

## 处理整合包

### 1. 选择模式

在 DeEarth 界面中，您可以选择两种工作模式：

- **开服模式**：下载服务端和模组加载器，完整生成服务端，适合首次创建服务端
- **上传模式**：只做模组筛选，不下载服务端文件，适合已有服务端需要更新模组的情况

### 2. 上传文件

1. 点击「选择文件」按钮
2. 在弹出的文件选择对话框中，选择您的整合包文件（支持 Zip 格式）
3. 点击「打开」按钮开始上传
4. 等待文件上传完成，上传进度会在界面上显示

### 3. 处理过程

上传完成后，软件会自动开始处理整合包，处理过程包括以下步骤：

1. **分析整合包**：识别整合包的模组加载器类型和版本，检测整合包的结构
2. **筛选模组**：自动区分客户端和服务端模组，剔除客户端专用的模组（如光影、材质包、小地图等）
3. **下载服务端**（开服模式）：根据整合包的版本和加载器类型，下载对应的服务端和模组加载器
4. **配置服务端**：生成服务端配置文件，包括服务器属性、模组配置等
5. **打包生成**：将处理后的文件打包成服务端

处理过程中，您可以看到实时的处理进度、当前执行的步骤和详细的日志信息。

### 4. 处理结果

处理完成后，您可以：

1. 查看处理结果，包括保留的模组和剔除的模组列表
2. 查看详细的处理日志，了解处理过程中的每个步骤
3. 点击「下载」按钮获取生成的服务端
4. 选择保存位置，保存服务端文件
5. 下载完成后，您可以解压缩服务端文件并启动服务器

## 模板管理

### 1. 本地模板

在 Galaxy 界面中，您可以管理本地模板：

#### 创建模板

1. 点击「创建模板」按钮
2. 填写模板基本信息：
   - 模板名称：模板的唯一标识
   - 描述：模板的详细说明
   - 版本：模板版本号
   - Minecraft 版本：适用的 Minecraft 版本
   - 模组加载器：适用的模组加载器（Forge、NeoForge、Fabric）
3. 配置模板参数：
   - 服务端配置：内存分配、启动参数等
   - 服务器属性：游戏规则、难度、模式等
   - 模组配置：预设的模组列表
4. 点击「保存」按钮，完成模板创建

#### 编辑模板

1. 在本地模板列表中选择要编辑的模板
2. 点击「编辑」按钮
3. 修改模板信息和配置参数
4. 点击「保存」按钮，完成模板编辑

#### 删除模板

1. 在本地模板列表中选择要删除的模板
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」按钮，确认删除

#### 导出模板

1. 在本地模板列表中选择要导出的模板
2. 点击「导出」按钮
3. 选择保存位置，保存模板文件（.dextpl 格式）
4. 导出的模板可以与其他用户共享

#### 导入模板

1. 点击「导入模板」按钮
2. 选择要导入的模板文件（.dextpl 格式）
3. 点击「打开」按钮
4. 查看模板信息，确认导入
5. 导入的模板会自动添加到本地模板列表

### 2. 模板商店

在 Galaxy 界面中，您可以浏览和下载远程模板：

1. 点击「模板商店」选项卡
2. 浏览可用的模板，您可以通过以下方式筛选：
   - 按 Minecraft 版本筛选
   - 按模组加载器类型筛选
   - 按模板类型筛选
3. 点击模板卡片查看详细信息，包括：
   - 模板名称和描述
   - 适用的 Minecraft 版本和模组加载器
   - 模板版本和更新时间
   - 模板作者和下载次数
4. 点击「下载」按钮获取模板
5. 下载的模板会自动添加到本地模板列表

## 设置

在 Setting 界面中，您可以配置软件的各项设置：

### 1. 基本设置

- **语言**：选择软件界面语言（支持中文、英文等多种语言）
- **主题**：选择软件主题（浅色/深色）
- **下载目录**：设置默认的下载目录，用于保存生成的服务端和下载的模板
- **自动检查更新**：开启或关闭自动检查更新功能

### 2. 网络设置

- **镜像源**：选择 Minecraft 资源下载镜像源（BMCLAPI、MCIM 等）
- **下载线程数**：设置下载线程数，影响下载速度（建议设置为 4-8）
- **超时设置**：设置网络连接超时时间（默认 30 秒）
- **代理设置**：配置 HTTP 代理（可选）

### 3. 高级设置

- **后端端口**：设置后端服务端口（默认 37019）
- **日志级别**：设置日志输出级别（调试、信息、警告、错误）
- **清理缓存**：清理软件缓存，释放磁盘空间
- **自动保存设置**：开启或关闭自动保存设置功能

### 4. 筛选设置

- **启用智能筛选**：开启或关闭智能模组筛选功能
- **自定义筛选规则**：添加、编辑、删除自定义的模组筛选规则
- **筛选日志**：查看模组筛选的详细日志

## 常见操作

### 如何判断模组是否为客户端专用

- **客户端专用模组**：光影、材质包、小地图、HUD 美化、客户端优化等
- **服务端模组**：核心模组、插件、性能优化、反作弊等
- **通用模组**：大部分功能模组同时支持客户端和服务端

### 如何选择合适的模式

- **开服模式**：适合首次创建服务端，需要完整的服务端文件
- **上传模式**：适合已有服务端，只需要更新模组

### 如何处理处理失败的情况

1. 检查整合包格式是否正确（Zip 格式）
2. 确保整合包文件完整，没有损坏
3. 检查网络连接是否正常（开服模式需要下载服务端）
4. 检查磁盘空间是否充足
5. 查看错误信息，根据错误码参考文档解决问题
6. 尝试重新上传整合包

### 如何更新模板

1. 在本地模板列表中选择要更新的模板
2. 点击「编辑」按钮
3. 修改模板信息和配置
4. 点击「保存」按钮
5. 如果需要，导出更新后的模板与其他用户共享

### 如何使用模板

1. 在处理整合包时，选择「应用模板」选项
2. 从本地模板列表中选择要使用的模板
3. 软件会根据模板配置处理整合包
4. 处理完成后，生成的服务端会包含模板中配置的参数

## 高级功能

### 1. 自定义筛选规则

您可以在设置中配置自定义的模组筛选规则，提高筛选的准确性：

1. 进入设置界面，点击「筛选设置」选项
2. 点击「添加规则」按钮
3. 设置规则名称、规则类型和规则内容
4. 点击「保存」按钮
5. 自定义规则会在模组筛选时被应用

### 2. 批量处理

您可以同时处理多个整合包，提高工作效率：

1. 在 DeEarth 界面中，点击「批量处理」按钮
2. 选择多个整合包文件
3. 选择处理模式（开服模式或上传模式）
4. 点击「开始处理」按钮
5. 软件会依次处理每个整合包

### 3. 模板导入导出

您可以导出本地模板为文件，与其他用户共享，或导入其他用户的模板：

- **导出模板**：选择本地模板，点击「导出」按钮，保存为 .dextpl 文件
- **导入模板**：点击「导入模板」按钮，选择 .dextpl 文件，导入到本地模板列表

### 4. 智能下载加速

软件内置智能下载速度测试，自动选择最快的下载链接，提高下载速度：

1. 在网络设置中，开启「智能下载加速」功能
2. 软件会自动测试不同镜像源的下载速度
3. 选择速度最快的镜像源进行下载

### 5. 服务端配置自定义

您可以在处理整合包时，自定义服务端配置：

1. 在处理整合包时，选择「自定义配置」选项
2. 设置服务端内存分配、启动参数等
3. 配置服务器属性，如游戏规则、难度、模式等
4. 点击「确认」按钮
5. 软件会根据您的配置生成服务端

## 注意事项

1. **文件大小限制**：建议整合包大小不超过 1GB，过大的文件可能会导致处理失败
2. **网络连接**：开服模式需要稳定的网络连接，用于下载服务端和模组加载器
3. **Java 环境**：开服模式需要安装 Java 17 或更高版本
4. **权限问题**：建议以管理员身份运行软件，避免权限问题
5. **模组兼容性**：处理后的服务端可能存在模组兼容性问题，请自行测试
6. **备份**：在处理整合包前，建议备份原始整合包文件
7. **模板兼容性**：使用模板时，确保模板与整合包的 Minecraft 版本和模组加载器兼容

## 故障排除

### 问题：整合包处理失败

**解决方案**：
- 检查整合包格式是否正确（Zip 格式）
- 确保整合包文件完整，没有损坏
- 检查网络连接是否正常（开服模式需要下载服务端）
- 检查磁盘空间是否充足
- 查看错误信息，根据错误码参考文档解决问题
- 尝试使用上传模式处理整合包

### 问题：服务端无法启动

**解决方案**：
- 确保已安装正确版本的 Java（Java 17 或更高版本）
- 检查服务端文件是否完整
- 查看服务端日志文件了解具体错误
- 检查模组兼容性
- 确保服务器端口没有被占用
- 尝试调整服务端内存分配

### 问题：模板下载失败

**解决方案**：
- 检查网络连接是否正常
- 稍后重试
- 检查模板商店服务器是否可访问
- 尝试使用其他网络环境

### 问题：软件运行缓慢

**解决方案**：
- 关闭其他占用系统资源的应用程序
- 增加系统内存
- 清理磁盘空间
- 检查网络连接速度
- 降低下载线程数

### 问题：模组筛选不准确

**解决方案**：
- 开启智能筛选功能
- 添加自定义筛选规则
- 手动检查筛选结果，调整筛选规则
- 反馈问题给开发团队

如果您遇到其他问题，请参考 [错误码](../error-codes.md) 文档或联系技术支持。
