# 快速开始

本指南将帮助您快速上手 DeEarthX-CE 软件，了解基本操作流程。

## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **操作系统**：Windows 10/11（64位）
- **开服模式**：需要 Java 17 或更高版本
- **上传模式**：不需要 Java
- **内存**：至少 4GB RAM（推荐 8GB 以上）
- **存储空间**：至少 2GB 可用空间（推荐 5GB 以上）
- **网络连接**：稳定的互联网连接（开服模式需要）

## 安装步骤

### 1. 下载软件

- 访问 [GitHub 仓库](https://git.xcclyc.com.cn/xcclyc/DeEarthX-CE) 下载最新版本的 DeEarthX-CE
- 选择适合您系统的安装包（Windows 64位）

### 2. 安装软件

1. 双击下载的安装包文件
2. 在弹出的安装向导中，点击「下一步」
3. 阅读并同意软件许可协议
4. 选择安装目录（建议不要安装在 C 盘，避免权限问题）
5. 选择是否创建桌面快捷方式
6. 点击「安装」按钮开始安装
7. 安装完成后，点击「完成」按钮

### 3. 启动软件

- 双击桌面快捷方式启动 DeEarthX-CE
- 或从开始菜单中找到并启动 DeEarthX-CE

## 首次使用

### 1. 主界面

启动 DeEarthX-CE 后，您将看到主界面，包含以下选项：

- **DeEarth**：主功能界面，用于处理整合包
- **Galaxy**：模板管理界面
- **Setting**：设置界面
- **About**：关于界面

### 2. 处理整合包

#### 2.1 选择模式

在 DeEarth 界面中，您可以选择两种工作模式：

- **开服模式**：下载服务端和模组加载器，完整生成服务端
- **上传模式**：只做模组筛选，不下载服务端文件

#### 2.2 上传文件

1. 点击「选择文件」按钮
2. 在弹出的文件选择对话框中，选择您的整合包文件
3. 点击「打开」按钮开始上传
4. 等待文件上传完成

#### 2.3 处理过程

上传完成后，软件会自动开始处理整合包：

1. **分析整合包**：识别整合包的模组加载器类型和版本
2. **筛选模组**：自动区分客户端和服务端模组，剔除客户端专用的模组（如光影、材质包等）
3. **下载服务端**（开服模式）：根据整合包的版本和加载器类型，下载对应的服务端和模组加载器
4. **配置服务端**：生成服务端配置文件，包括服务器属性、模组配置等
5. **打包生成**：将处理后的文件打包成服务端

处理过程中，您可以看到实时的处理进度和日志信息。

#### 2.4 下载服务端

处理完成后，您可以：

1. 查看处理结果，包括保留的模组和剔除的模组
2. 点击「下载」按钮获取生成的服务端
3. 选择保存位置，保存服务端文件
4. 下载完成后，您可以解压缩服务端文件并启动服务器

### 3. 模板管理

#### 3.1 进入模板管理

- 点击左侧导航栏中的「Galaxy」选项

#### 3.2 本地模板

- **创建模板**：点击「创建模板」按钮，填写模板名称、描述、版本等信息，配置模板参数，点击「保存」按钮
- **编辑模板**：选择已有模板，点击「编辑」按钮，修改模板信息和配置，点击「保存」按钮
- **删除模板**：选择已有模板，点击「删除」按钮，在确认对话框中点击「确定」按钮
- **导出模板**：选择已有模板，点击「导出」按钮，选择保存位置，保存模板文件

#### 3.3 模板商店

- 点击「模板商店」选项卡
- 浏览可用的模板
- 点击模板卡片查看详细信息
- 点击「下载」按钮获取模板
- 下载的模板会自动添加到本地模板列表

## 常见问题

### 问题：软件启动失败

**解决方案**：
- 检查系统是否满足最低要求
- 尝试以管理员身份运行软件
- 确保安装路径没有特殊字符
- 检查 37019 端口是否被占用
- 查看软件日志文件了解具体错误

### 问题：整合包处理失败

**解决方案**：
- 检查整合包格式是否正确
- 确保整合包文件完整，没有损坏
- 检查网络连接是否正常（开服模式需要下载服务端）
- 检查磁盘空间是否充足
- 查看错误信息，根据错误码参考文档解决问题

### 问题：服务端无法启动

**解决方案**：
- 确保已安装正确版本的 Java（Java 17 或更高版本，建议Java 21）
- 检查服务端文件是否完整
- 查看服务端日志文件了解具体错误
- 检查模组兼容性
- 确保服务器端口没有被占用

### 问题：模板下载失败

**解决方案**：
- 检查网络连接是否正常
- 稍后重试
- 检查模板商店服务器是否可访问

### 问题：软件运行缓慢

**解决方案**：
- 关闭其他占用系统资源的应用程序
- 增加系统内存
- 清理磁盘空间
- 检查网络连接速度

如果您遇到其他问题，请参考 [错误码](./../error-codes.md) 文档或联系技术支持。
