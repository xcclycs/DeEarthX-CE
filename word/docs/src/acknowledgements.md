## 技术支持

- **Node.js**：提供后端运行环境
- **Vue 3**：前端框架
- **Tauri**：桌面应用框架
- **TypeScript**：类型安全的编程语言
- **Ant Design Vue**：UI 组件库
- **Tailwind CSS**：样式框架

## 开源依赖

- **express**：后端 Web 服务
- **ws**：WebSocket 通信
- **yauzl**：ZIP 文件处理
- **axios**：HTTP 请求
- **vue-router**：前端路由
- **i18n**：国际化支持

## 镜像源支持

- **BMCLAPI**：Minecraft 资源加速下载
- **MCIM**：Minecraft 镜像源
