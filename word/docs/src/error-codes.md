# 错误码参考

本文档列出了 DeEarthX-CE 软件中可能出现的错误码及其解决方案。

## 后端启动相关错误

| 错误码 | 错误信息 | 解决方案 |
|--------|----------|----------|
| 1001 | 后端服务启动失败 | - 检查 37019 端口是否被占用<br>- 检查后端服务是否正常<br>- 重启应用程序 |
| 1002 | 后端服务端口被占用 | - 关闭占用 37019 端口的其他应用<br>- 检查是否有其他 DeEarthX 实例在运行<br>- 重启计算机后再试 |
| 1003 | 后端服务连接失败 | - 检查后端服务是否正在运行<br>- 检查网络连接是否正常<br>- 重启应用程序 |
| 1004 | 后端服务响应错误 | - 检查后端服务是否正常<br>- 重启后端服务<br>- 联系技术支持 |

## 网络相关错误

| 错误码 | 错误信息 | 解决方案 |
|--------|----------|----------|
| 2001 | 网络连接错误 | - 检查网络连接是否正常<br>- 检查防火墙设置<br>- 稍后重试 |
| 2002 | 网络连接超时 | - 检查网络连接速度<br>- 稍后重试<br>- 检查目标服务器是否可访问 |
| 2003 | 网络连接被拒绝 | - 检查目标服务器是否正在运行<br>- 检查网络连接是否正常<br>- 检查防火墙设置 |

## 文件相关错误

| 错误码 | 错误信息 | 解决方案 |
|--------|----------|----------|
| 3001 | 文件未找到 | - 确认文件路径是否正确<br>- 检查文件是否存在<br>- 重新上传文件 |
| 3002 | 文件权限错误 | - 检查文件权限设置<br>- 以管理员身份运行应用程序<br>- 检查文件是否被其他程序占用 |
| 3003 | 文件格式错误 | - 确认文件格式是否正确<br>- 重新上传正确格式的文件<br>- 检查文件是否损坏 |
| 3004 | 文件大小错误 | - 检查文件大小是否符合要求<br>- 压缩文件后再上传<br>- 检查磁盘空间是否充足 |

## 系统相关错误

| 错误码 | 错误信息 | 解决方案 |
|--------|----------|----------|
| 4001 | Java 未找到 | - 安装 Java 17 或更高版本<br>- 配置 Java 环境变量<br>- 重启应用程序 |
| 4002 | 磁盘空间不足 | - 清理磁盘空间<br>- 选择其他存储位置<br>- 删除不必要的文件 |
| 4003 | 内存不足 | - 增加系统内存<br>- 关闭其他占用内存的应用程序<br>- 减少同时处理的任务数量 |

## 未知错误

| 错误码 | 错误信息 | 解决方案 |
|--------|----------|----------|
| 9999 | 未知错误 | - 重启应用程序<br>- 检查系统日志<br>- 联系技术支持 |

## 错误处理建议

1. **查看详细错误信息**：当出现错误时，仔细阅读错误信息，了解具体问题
2. **按照解决方案尝试**：根据错误码对应的解决方案尝试解决问题
3. **重启应用程序**：如果问题仍然存在，尝试重启应用程序
4. **检查系统环境**：确保系统满足软件的最低要求
5. **联系技术支持**：如果问题无法解决，联系技术支持获取帮助

## 如何避免常见错误

1. **确保网络连接稳定**：在使用开服模式时，确保网络连接稳定，避免下载中断
2. **使用正确的文件格式**：确保上传的整合包是 Zip 格式，且文件完整
3. **安装 Java 环境**：在使用开服模式前，确保已安装正确版本的 Java
4. **保持足够的磁盘空间**：确保系统有足够的磁盘空间用于处理和存储文件
5. **以管理员身份运行**：在 Windows 系统上，建议以管理员身份运行软件，避免权限问题
