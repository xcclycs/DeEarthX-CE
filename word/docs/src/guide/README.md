# 使用指南

本目录包含 DeEarthX-CE 软件的详细使用指南，帮助您快速上手和掌握软件的各项功能。

## 指南目录

- [快速开始](quick-start.md)：快速上手 DeEarthX-CE 软件
- [使用指南](usage-guide.md)：详细介绍软件的使用方法
- [模板管理](template-management.md)：模板系统的使用指南

## 功能概览

- **整合包处理**：支持 CurseForge、Modrinth、MCBBS 等平台的整合包
- **智能模组筛选**：自动区分客户端和服务端模组
- **多加载器支持**：支持 Forge、NeoForge、Fabric 等主流模组加载器
- **模板管理**：创建、编辑、导入/导出模板，提供模板商店
- **多模式工作**：支持开服模式和上传模式

## 适用场景

- 服务器管理员快速制作服务端
- 整合包作者测试服务端兼容性
- 玩家自行搭建服务器
- 教育机构搭建 Minecraft 教学服务器

## 注意事项

- 建议以管理员身份运行软件，避免权限问题
- 开服模式需要安装 Java 17 或更高版本
- 整合包大小建议不超过 1GB，过大的文件可能会导致处理失败
- 处理后的服务端可能存在模组兼容性问题，请自行测试

如果您遇到问题，请参考 [错误码](../error-codes.md) 文档或联系技术支持。
